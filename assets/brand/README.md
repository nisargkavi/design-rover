# Design Rover brand assets

Prepared from the project owner's supplied logo. The blue and grey symbol and the two-line wordmark retain the supplied design; the surrounding whitespace has been removed. The wordmark is traced from the supplied PNG, rather than substituted with another font.

| File | Use |
| --- | --- |
| `logo.svg`, `logo.png` | Full logo, transparent background and black wordmark |
| `logo-dark.svg`, `logo-dark.png` | Full logo, transparent background and white wordmark |
| `icon.svg`, `icon.png` | Standalone symbol, transparent square canvas |
| `icon-mono.svg`, `icon-mono.png` | Standalone symbol in black |
| `readme-banner.svg`, `readme-banner.png` | GitHub README banner, light background |
| `readme-banner-dark.svg`, `readme-banner-dark.png` | GitHub README banner, dark background |

The SVG files contain vector paths only, with outlined lettering and no embedded raster artwork or external font dependencies. PNG logos are exported with transparency: full logos at 2400 x 768 and symbols at 1024 x 1024. The square symbol exports include padding for circular avatars. Banners are 1600 x 560.

Original colours: blue `#38B6FF`, grey `#B4B4B4`, wordmark `#000000`. The dark logo uses white lettering. The README switches banners using `prefers-color-scheme`.

The additional banner caption uses outlined Manrope lettering; its command uses outlined JetBrains Mono lettering. Their SIL Open Font License notices are included. No font files are distributed. The primary logo wordmark remains the owner-supplied artwork.
